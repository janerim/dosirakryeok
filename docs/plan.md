# 도시락력 기획서

Nov 11, 2026 · @ryubi

## 개요

도시락력은 주말에 한 번 준비해서 평일 도시락 5일을 해결하게 해주는, 1인 가구 직장인용 도시락 달력이다. 레시피 앱이 아니라 산 재료를 끝까지 쓰게 해주는 앱이라는 점이 차별점이다.

| 풀려는 문제 | 앱이 해주는 일 |
| --- | --- |
| 혼자 먹으니 재료가 남아 냉동실로 들어간다 | 한 번 산 재료로 그 주 도시락 여러 개를 묶어 계획한다 |
| 냉동실에 들어가면 보이지 않아 잊어버린다 | 재료마다 보관 위치와 일수를 보여주고, 요일에 배정해 날짜를 붙인다 |
| 요리 실력이 없어 무엇을 쌀지 정하기 어렵다 | 보관 후 데워 먹어도 괜찮은 쉬운 메뉴만 보여준다 |

| 항목 | 내용 |
| --- | --- |
| 대상 | 점심 도시락을 싸는 1인 가구 직장인 (첫 사용자는 나) |
| 기준 단위 | 1주. 주말에 준비하고 평일에 꺼내 간다 |
| 시리즈 | 력 시리즈 다섯 번째 앱. 메인 화면은 달력 |

## 일주일 흐름

> (원문의 도식 "일주일 흐름 · 4단계, 매주 반복"은 마크다운 내보내기에서 빠졌다. 원문: https://claude.ai/artifact/QqVnspr8CWRmWhH9pax83F)

손이 가는 단계는 주말 한 번뿐이다. 냉동실에 들어가는 것이 "언젠가 쓸 재료"가 아니라 요일이 붙은 도시락이라서 잊어버리지 않는다.

## MVP 기능

1차는 다섯 가지 기능으로 일주일 흐름을 한 바퀴 돌릴 수 있게 만든다. 입력이 귀찮으면 안 쓰게 되므로 재료 등록을 빠르게 만드는 것이 가장 중요하다.

| 기능 | 내용 |
| --- | --- |
| 달력 홈 | 요일마다 도시락 하나. 먹은 날은 채워지고, 오래된 재료가 있으면 표시한다 |
| 재료 등록 | 이름, 보관 위치(냉장·냉동·실온), 넣은 날짜만 입력한다. 자주 사는 재료는 탭 한 번으로 추가한다 |
| 주간 계획 | 보유 재료와 많이 겹치는 순으로 메뉴를 보여주고, 고른 메뉴를 평일 5칸에 배치한다 |
| 장보기 목록 | 계획한 메뉴에 필요한 재료 중 없는 것만 모아 보여준다 |
| 알림 | 평일 아침 오늘 도시락, 오래 보관한 재료, 금요일 저녁 다음 주 계획 알림 |

### 2차 이후

- 가계력 연동: 식비를 기록할 때 재료 등록으로 넘기기
- 도시락으로 아낀 점심값 통계
- 영수증 인식, 바코드 스캔으로 재료 등록
- 보유 재료 기반 AI 메뉴 제안
- 내 레시피 직접 추가와 사진 기록

## 화면 구성

| 화면 | 보여주는 것 |
| --- | --- |
| 달력 (홈) | 이번 달 도시락 기록과 오늘 메뉴 |
| 냉장고 | 보관 위치별 재료와 보관 일수 |
| 이번 주 | 평일 5칸 배치와 주말 준비 순서 |
| 레시피 | 재료, 조리 순서, 보관 방법 |
| 장보기 | 부족한 재료 체크리스트 |

## 데이터 모델과 기술 스택

가계력과 같은 Expo + SQLite 로컬 저장 구조로 시작하고, 서버는 두지 않는다. 달력 홈은 책력·가계력의 것을 재사용하고, 알림은 로컬 알림으로, 레시피는 앱에 내장한 데이터로 시작한다.

| 테이블 | 주요 필드 |
| --- | --- |
| ingredient | 이름, 보관 위치, 넣은 날짜, 남은 양, 소진 여부 |
| recipe | 이름, 조리 시간, 조리 순서, 보관 방법, 보관 가능 일수 |
| recipe\_ingredient | 레시피, 재료 이름, 필요한 양 |
| meal\_plan | 날짜, 레시피, 상태(계획·준비됨·먹음·건너뜀) |
| shopping\_item | 주, 재료 이름, 양, 구매 여부 |

## 4주 MVP 일정 (안)

가계력 MVP와 같은 4주를 기준으로 잡은 제안이며, 착수 시점은 아직 정하지 않았다.

| 주차 | 목표 | 할 일 |
| --- | --- | --- |
| 1주차 | 뼈대와 재료 | DB 스키마, 달력 홈 이식, 재료 등록과 냉장고 화면 |
| 2주차 | 레시피와 계획 | 내장 레시피 데이터, 재료 겹침 순 정렬, 평일 5칸 배치 |
| 3주차 | 장보기와 알림 | 장보기 목록, 먹음 체크와 재고 차감, 알림 세 가지 |
| 4주차 | 직접 써보기 | 한 주를 실제로 돌려 보고 입력이 귀찮은 곳을 줄인 뒤 테스트플라이트 |

## 아직 정하지 않은 것

- [ ] 레시피 출처: 직접 큐레이션(제안: 20\~30개로 시작)과 AI 생성 중 선택
- [ ] 착수 시점: 가계력 배포와 소식력 개발 이후로 둘지
- [ ] 재료 양 입력: 그램 단위로 받을지, "있음·조금·없음" 정도로 단순화할지
- [ ] 저녁·주말 식사: 도시락만 다룰지, 남은 재료로 저녁까지 제안할지
