# App Store 등록 문구

App Store Connect 에 그대로 붙여 넣는 텍스트다. 형식과 문장은 집중력·책력·가계력 저장소의
`docs/appstore-metadata.md` 와 맞췄다. 스토어에서 직접 고치면 무엇을 왜 바꿨는지 남지
않으니, 고칠 때는 이 파일을 먼저 고친다.

각 항목의 글자 수 제한이 다르고 한글도 한 글자로 센다. 아래 숫자는 현재 길이다.
언어는 한국어 하나만 둔다.

> **초안이다 (2026-11-11).** 앱은 아직 빈 탭 5개와 달력 틀만 있다. 아래 문구는
> [plan.md](plan.md) 의 MVP 기능을 보고 미리 쓴 것이라, 제출 전에 실제로 만든 기능만 남긴다.

## 부제 (10 / 30자)

> 집중력의 "나만의 집중 타이머", 책력의 "나만의 독서 달력", 가계력의 "나만의 가계부 달력" 과 짝을 이룬다.
> 앱 이름은 이미 함께 표시되므로 넣지 않는다.

```
나만의 도시락 달력
```

## 프로모션 텍스트 (69 / 170자)

> 빌드를 새로 올리지 않고도 언제든 바꿀 수 있는 항목이다.
> 둘째 줄은 집중력·책력·가계력과 함께 쓰는 문장이다. 바꾸려면 세 앱 쪽도 같이 바꾼다.

```
주말에 한 번 준비하면 평일 닷새 도시락이 달력에 놓입니다. 산 재료를 끝까지 쓰게 됩니다.
하루하루가 쌓여 기록이 됩니다.
```

## 설명 (607 / 4000자)

> 첫 세 줄만 접히지 않고 보인다. 거기서 이 앱이 무엇인지 끝나야 한다.
> 마지막 줄은 프로모션 텍스트 둘째 줄과 같은, 집중력·책력·가계력과 함께 쓰는 문장이다.
> 2차 이후 기능(가계력 연동, 점심값 통계, 영수증·바코드, AI 메뉴 제안, 내 레시피)은 쓰지 않는다.
> "어디로도 전송되지 않습니다" 는 앱에 네트워크 통신이 없는 동안만 쓸 수 있다. 지금은 저장되는 곳만 말한다.

```
도시락력은 주말에 한 번 준비해서 평일 도시락 닷새를 해결하는 도시락 달력입니다.

산 재료로 그 주 도시락을 묶어 계획하고, 요일마다 하나씩 달력에 놓습니다.


■ 달력으로 한눈에

요일마다 도시락 하나가 놓입니다. 먹은 날은 채워집니다.
오래 보관한 재료가 있으면 달력에서 알려 줍니다.


■ 냉장고에 뭐가 있는지

재료 이름, 보관 위치, 넣은 날짜만 적습니다.
자주 사는 재료는 한 번 눌러 추가합니다.
냉장, 냉동, 실온으로 나눠 며칠째 보관 중인지 보여 줍니다.


■ 이번 주 계획

가진 재료와 많이 겹치는 메뉴부터 보여 줍니다.
고른 메뉴를 평일 다섯 칸에 놓으면 주말에 준비할 순서가 정리됩니다.


■ 쉬운 레시피

보관했다가 데워 먹어도 괜찮은 메뉴만 담았습니다.
재료, 조리 순서, 보관 방법을 함께 봅니다.


■ 장보기 목록

계획한 메뉴에 필요한 재료 중 없는 것만 모아 줍니다.


■ 알림

평일 아침에는 오늘 도시락을, 금요일 저녁에는 다음 주 계획을 알려 줍니다.
오래 보관한 재료도 잊기 전에 알려 줍니다.


■ 기록은 이 기기 안에

재료와 계획은 이 기기 안에만 저장되고, 앱을 지우면 함께 사라집니다.


하루하루가 쌓여 기록이 됩니다.
```

## 그 밖의 항목

| 항목 | 값 |
|---|---|
| 카테고리 (기본) | 미정 — 후보는 음식 및 음료, 라이프스타일(책력과 같음) |
| 카테고리 (보조) | 미정 |
| 연령 등급 | 4+ |
| 가격 | 무료 |
| 언어 | 한국어만 — 영어(미국) 로컬라이제이션은 지운다. 기본 언어가 한국어인지 먼저 본다 |
| App Privacy | 미확인 — ASC 에 입력한 뒤 값을 옮겨 적는다 |
| 개인정보 처리방침 URL | 미정 — `docs/privacy.md` 가 아직 없다 |
| 지원 URL (필수) | 미정 — `docs/support.md` 가 아직 없다 |
| 마케팅 URL | 비워 둔다. 홍보용 랜딩 페이지가 없다 |
| 버전 | `0.1.0` — 업로드한 빌드의 `version` 과 같아야 한다. 첫 제출 때 `1.0.0` 으로 올릴지 정한다 |
| 저작권 | `© 2026 ryubi` |

## 심사 메모

> 심사 중에 막힐 만한 것을 미리 적어 둔다. 계정이 없고, 알림 권한을 요청한다.

```
로그인이나 계정 없이 바로 사용할 수 있습니다.

앱은 서버가 없으며 재료와 식단 계획은 기기 안에만 저장합니다.

알림은 기기 안에서 예약하는 로컬 알림이며, 오늘 도시락과 오래 보관한 재료, 다음 주 계획을 알려 주는 데 씁니다.
```
